# *Project Firefly*

*You can take my love, you can take my land; but you can't take the sky from me!*

### A collection of highly optimized binaries for use with *Zen3+* systems

These binaries have been compiled with extreme optimizations, and specifically using the AOCC v6 compiler for any C-Language code chunks or modules.

The optimizations have been applied to both the AOCC compiler as well as the native compiler for extreme performance.

Containers are organized by tags of their respective binaries, are prebuilt, and labeled thusly: 
```
#__Crun__#
ghcr.io/celestial-uprising/firefly:crun

#__Podman__#
ghcr.io/celestial-uprising/firefly:podman
```
